# AI书桌 Plugin · 1.0.8

AI书桌在 Codex 中帮助用户澄清本人目标、衔接独立目标任务、记录必要进展与成果，并按本人意愿分享和继续工作。每人使用自己的账号和书桌。

本仓库提供 `1.0.8+codex.20261002005145` 的 Plugin 包与配套元数据。代码分发不等于全部用户路径已经验收或社区已经开放。

## 这次修复带来什么

服务受理产生的本机恢复记录，现在能关联到请求中的准确目标，随该目标导出和清理。之前这类请求使用 `goalRef.goalId`，记录没有保存目标关联；调用前后 Hook 虽然执行，按目标筛选时仍会遗漏两条摘要。

修复只处理正式目标服务请求的明确引用，并在目标编号相互冲突时拒绝错误关联。其他工具的目标选择方式保持原合同，不从任意嵌套正文猜目标归属。既有缺少关联的记录不会因升级自动补写；只能依据准确原请求核对，不通过重放业务补账。

既有目标协作、结果记录与更正、分享撤回、互动与通知、受限恢复账本和官方 CLI 更新能力继续提供。草稿及既有私人目标不会因分享默认值而自动公开。

## 安装与使用

官网：[aideskx.com](https://aideskx.com)。沿 Codex 官方 Plugin 机制安装或更新 AI书桌，在新对话中说“打开AI书桌”。产品介绍不要求登录；本人服务通过宿主原生认证核对身份及权限。

本包不写死长期 CLI 版本。宿主需要支持包内 CLI-native 声明、MCP 与 Hook；启用和信任按宿主正常流程办理。磁盘安装成功不代表已有会话已经加载新连接。发行元数据最低支持版本保持 `1.0.5+codex.20261001120032`；社区功能受服务端开关、账号权限及实际工具目录控制。
