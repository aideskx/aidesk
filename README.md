# AI 书桌

围绕一个当前问题，在对话中澄清想法、选择方法，推进到可验证的下一步。工作台用于写下问题并交给对话，模型保留自主判断。

本说明适用于插件包 **2.0.0**。

**当前是开发候选，未发布、未完成外部用户验收。** 必须先部署服务 0.3.0 或更高兼容版本，并在独立验证分支验收后，才可推进公开 main。当前 main 上的历史版本不是本候选。

## 安装与注册登录

目标是使用支持 Git 插件市场的 Codex 桌面的外部用户。无需加入维护者的工作区，也不依赖维护者私人云端应用的访问资格；仍需满足 Codex、WorkOS 等服务本身的账号与使用条件。网页、手机及其他宿主尚未验收。

候选验收时，使用维护者交付的固定提交替换 `<已核对的候选提交>`：

```bash
codex plugin marketplace add aideskx/aidesk --ref <已核对的候选提交>
codex plugin add aidesk-minimal@aidesk-minimal-local
```

正式发布后再使用 `--ref main` 跟踪更新。市场名和插件名固定，安装不需要再创建“开发验收”云端插件。

1. 安装后打开 AI 书桌，按宿主提示认证；也可在设置的 MCP 服务器中选中插件提供的 AI 书桌连接并选择 Authenticate／认证。
2. 在 WorkOS 托管页面输入自己的邮箱，完成验证码及授权。新用户按页面完成注册，已有用户登录；验证码只填写在该页面。
3. 回到宿主，打开新工作台并检查账号状态。登录成功后才能调用 AI 书桌服务。

需要 CLI 登录时，先用 `codex mcp list` 核对实际服务器名称，再执行 `codex mcp login <实际服务器名称>`。不要猜测插件命名空间，不要另加同地址服务器以掩盖安装问题。若 CLI 没列出插件提供的连接，使用宿主设置中的认证入口。认证失败时保留脱敏错误，按支持说明反馈。

插件固定连接 `https://aideskx.com/mcp`。GitHub 负责分发文件；WorkOS 和宿主管理用户登录；AI 书桌服务端逐请求验证身份。安装包不包含令牌、验证码或维护者的账号。

## 使用工作台

1. 打开“AI 书桌”，完成连接检查；输入当前的一个问题，最多 4000 字符。
2. 点击“交给对话继续”。工作台先调用受保护的“推进一个问题”工具；服务端确认身份及允许使用后，才把原文交给宿主对话。
3. 未登录、授权失效、权限拒绝或检查失败时不交接，草稿保留在当前页面。重新认证成功后由你主动再次提交。
4. “已交给对话”只表示宿主收到问题，后续回应在关联对话中查看。结果未知时先查看对话，不要自动重复发送。

不支持工具调用或消息交接的宿主会给出说明。可复制自己的草稿到普通对话；这不表示已使用或获得 AI 书桌服务权限。普通 ChatGPT/Codex 对话以及公开 Skill 文件无法由 AI 书桌的账号体系限制。账号权限的安全检查位于服务端，按钮状态和 Skill 文案只是使用指导。

工作台只保留页面内存中的草稿和状态，关闭或刷新会丢失草稿。已发出的消息按宿主设置处理。Git 版账号入口可能与云端原生账户卡片不同；不承诺相同的多账号列表界面。

## 更新

正式版发布后，保持同一市场和插件身份：

```bash
codex plugin marketplace upgrade aidesk-minimal-local
```

跟踪 main 才会取得后续 main 版本；固定提交适合验证或冻结，不会自行跟随新提交。查看 [版本说明](CHANGELOG.md)，核对同一插件的准确版本、Git revision 和校验清单，再重新打开需要加载新版的会话或工作台。不得手改安装缓存或重发同版本不同内容。

更新目标是保留当前账号连接，只有凭证确实失效时重新认证；是否达成须真实验收。将“后台自行更新”“启动后更新”“手动触发升级”分别记录，不能将 marketplace upgrade 的成功称作自动更新。个人 Git 市场没有已核实的固定后台周期；本包没有自制更新器或轮询任务。

插件文件与服务分别发布。工作台和权限检查由远程服务提供，固定 Git 版本不会冻结服务版本。服务变更先验证兼容性，再发布插件；失败恢复使用已核对的版本和普通 Git 提交，不移动旧标签。

## 断开与移除

在宿主 MCP 连接设置中断开账号；CLI 管理时先确认实际服务器名称，再执行 `codex mcp logout <实际服务器名称>`。卸载插件和删除账号是不同操作：

```bash
codex plugin remove aidesk-minimal@aidesk-minimal-local
codex plugin marketplace remove aidesk-minimal-local
```

它们不会代为删除宿主对话或 WorkOS 账号，也不意味着已签发凭证立即失效。若有两个同名入口，先核对来源和内部身份，只移除已经确认的重复安装。
