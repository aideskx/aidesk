安装后新建任务，发送“打开AI书桌”。官网：https://aideskx.com

当前包版本 `0.3.2+codex.20260919141235`。同一个 Plugin 包含入口 Skill、MCP 连接、更新程序和教学接线；仍为开发验证范围，真实家庭尚未开放。账号与教学能力以实际授权和服务返回为准。

本版精简本机入口指引。正常打开先检查官方更新，再用一次账号与上下文汇总调用取得学习者菜单；只读汇总不选择或绑定学习者。仅旧服务明确缺少汇总工具时使用兼容路径，认证、权限或读取失败不能降级绕过。检查状态未知或检查工具缺失时，最多执行一次包内只读补查，再按真实结果继续或停止。

进入教学仍须本人明确选择并通过服务核验；宿主通过同一 MCP 完整读取服务器当前活动且兼容的教学 Skill，读完主文件和全部附属文件后才组织教学。兼容教学内容可独立在服务器维护，无须每次更新 Plugin。未完整读取、失效或不兼容时停止依赖该包的教学。模块化、跨次缓存及完整开课提速尚未交付。

本版已在本机已有授权的新 CLI 会话中验证准确版本、两次 MCP 和学习者菜单；未自动选择或进入教学。该回合后的 CLI 退出有异常，测试进程已清理；不能将其称为整场全部通过。一次菜单结果不构成固定延迟承诺，也不证明 GUI、首次登录、完整教学或真实家庭效果。

本版公开安装与自动更新后的同候选路径尚未验收，MacBook／Windows同版本路径也尚未验收。此前教学与更新验证只覆盖当时记录的设备、版本和场景，不能替代本版受影响路径的复测。

打开AI书桌会检查官方稳定版本，需要时通过宿主官方 Plugin CLI 安装。可以明确要求只检查或暂不更新；必要确认仍然有效。检查失败不冒充最新版，已知强制更新要求不能被补查失败覆盖。下载与服务缓存可能延迟新版可见时间；发现新版、磁盘已安装与当前连接已加载分别核验。当前连接尚未刷新时先新建任务，仍旧再按实际停点处理。

插件标识、官方来源及登录机制保留。更新依赖宿主已有 Node（20+）、可核实的 Codex CLI 与执行能力；来源冲突、固定其他版本或缺少能力时说明停点，不自动卸载重装或改写配置。只读补查复用原更新与完整性所有者，不处理账号凭据。
