# AI书桌 Plugin 技术预发布

普通用户向 Codex 发送：

> 从GitHub安装Codex插件 aideskx/aidesk

安装后新建任务，发送“打开AI书桌”。官网：https://aideskx.com

当前版本 `0.3.2+codex.20260914062319`，同一插件包含入口 Skill、MCP 连接与一次性更新程序。账号与教学能力以实际授权和当前工具为准；教学功能尚未开放。

打开AI书桌会检查官方稳定版本，需要时通过宿主官方 Plugin CLI 安装。只想检查或暂不更新，可以明确告诉 Codex。不会关闭 Codex 后后台轮询；检查失败不会冒充最新版。发现新版、磁盘已安装、当前连接已加载是分别核验的状态；新任务仍使用旧连接时可能需要重启 Codex。

更新依赖宿主已有 Node（20+）、可核实的 Codex CLI 与执行能力，宿主必要确认仍然有效。来源冲突、固定其他版本或缺少执行能力时，会明确说明停点，并保留上方安装指令。现有不含自动更新程序的旧包需先沿此指令升级一次。本次本机自动更新验收正在进行，不能据此承诺所有宿主或跨设备均通过。

发布元数据 `release.json` 与完整包在同一 Git 提交中；更新程序从固定官方来源读取，安装后按 `packageDigest` 核验实际文件。当前摘要 `ae6322030fe44d28c4db6338f61f99a0bb9923cca3f3b99c7c6f10512620d4a6`，`SHA256SUMS` 覆盖全部7个包文件与发布元数据。上一可恢复公开提交 `af07dc13b877f2b98ac75986b04ab11d4e68ecde`（`0.3.1+codex.20260914054451`）保留在历史中，恢复必须使用同提交配套包与元数据，不自动降级。
