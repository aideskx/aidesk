# AI书桌 Plugin · 1.0.6

AI书桌在 Codex 中帮助用户澄清本人目标、衔接独立目标任务、记录必要进展与成果，并按本人意愿分享和接续。每人使用自己的账号和书桌。

本仓库提供 Plugin 分发包和配套元数据。公开 `main` 当前版本为 `1.0.6+codex.20261001192600`，已通过离线回归、fresh clone、release verify 和 1.0.5→1.0.6 官方 CLI 升级读回。交互式 Hook 信任、桌面 UI/AX、结果宿主采用和第二宿主核验仍需按实际环境读回，不能从包存在或离线测试推定全部功能已上线。


## 1.0.6 变化

- 更新器改为包内可执行的 CLI-native `scripts/update.mjs`，只沿官方 marketplace upgrade/add 路径更新，并对来源、版本、Git mode 摘要和安装后状态做有界核验。
- 更新器拒绝 marketplace 来源漂移并处理结构化 CLI 错误；失败时保留旧安装并返回可判定状态。
- 结果合同支持 `record/read/correct/operation`，四个结果工具纳入 Pre/Post 生命周期账本。
- 自然入口增加产品介绍、临时问题、清晰/模糊目标、暂不开始和明确分享的决策边界；不会因普通对话自动登录、写目标或公开内容。
- 数据权利明确区分更正、公开撤回和删除；`aidesk_goal_network_withdraw` 纳入写入 Hook 对账。

## 本版变化

- 修复 updater 对显式 `--codex <绝对路径>` 的参数消费，并补充来源漂移和结构化错误回归。

- CLI-native 包统一交付一个完整协作 Skill、同包按需说明、MCP 连接和四个显式 Hook。
- 修复 Hook 对合法操作对账、导出、删除预览及社区只读工具的错误拦截；可选请求摘要需与规范请求匹配，未知结果只沿原操作号核对。
- 补齐点赞、收藏、采用、评论与回复、通知、举报的操作说明及只读合同；服务端继续核对账号、权益、对象和社区准入。
- Post Hook 记录安全的回执摘要和状态观察，不写入完整正文、凭据或 Token；恢复继续使用主体/目标哈希、操作号和请求摘要。
- 新正式目标默认分享可关闭，用户可调整以后新目标的分享偏好；草稿和既有私人目标保留原状态。分享受社区开关和权限约束，保存目标不等于公开成功。
- 本机恢复记录支持摘要导出和精确目标清理，本机清理与服务端数据删除分别核对。

## 安装与使用

官网：[aideskx.com](https://aideskx.com)。沿 Codex 官方 Plugin 机制安装或更新 AI书桌，在新对话中说“打开AI书桌”。产品介绍不要求登录；本人服务通过宿主原生认证核对身份及权限。

本包不写死长期 CLI 版本。宿主需要支持包内 CLI-native 声明、MCP 与 Hook；启用和信任按宿主正常流程办理。磁盘安装成功不代表已有会话已经加载新连接。

最低支持版本设为 `1.0.5+codex.20261001120032`，不承诺旧包或旧宿主兼容。公开稳定源新装和 1.0.5→1.0.6 升级已完成隔离读回；跨设备路径仍未验。
