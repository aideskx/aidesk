# AI书桌 Plugin · 1.0.10

AI书桌在 Codex 中帮助用户澄清本人目标、衔接独立目标任务、记录必要进展与成果，并按本人意愿分享和继续工作。每人使用自己的账号和书桌。

本仓库提供 `1.0.10+codex.20261002022547` 的 Plugin 包与配套元数据。代码分发不等于全部用户路径已经验收或社区已经开放。

## 这次修复带来什么

本机更新器的 `--check` 不再取得需要写入的更新锁，避免仅检查版本也因不能写锁而中断。检查前后重新核对安装版本、来源与包字节；观察到变化或无法确认时返回未知、`changed:false`，不自动重试。这些有界读取不是宿主的原子快照，也不保证返回后没有其他变化；官方读取命令仍可能有宿主内部行为。

实际安装的 `--apply` 继续使用原排他锁与有界单次命令。未知安装结果不自动重试；固定阶段与白名单错误码诊断继续提供，释放锁失败仍保留已经确认的更新结果，不输出原始错误、路径或凭据。

此前 1.0.9 的一次真实自然入口检查已观察到 `lock_acquire/EPERM`，本次针对检查也写锁的原因修复。更早 1.0.8 失败未保留的原始 errno 仍无法倒推；这次修复和本地测试不能代替新版真实自然入口或全功能验收。

## 安装与使用

官网：[aideskx.com](https://aideskx.com)。沿 Codex 官方 Plugin 机制安装或更新 AI书桌，在新对话中说“打开AI书桌”。产品介绍不要求登录；本人服务通过宿主原生认证核对身份及权限。

本包不写死长期 CLI 版本。宿主需要支持包内 CLI-native 声明、MCP 与 Hook；启用和信任按宿主正常流程办理。磁盘安装成功不代表已有会话已经加载新连接。发行元数据最低支持版本保持 `1.0.5+codex.20261001120032`；社区功能受服务端开关、账号权限及实际工具目录控制。
