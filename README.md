# AI 书桌

围绕一个当前问题，在对话中澄清想法、选择方法，推进到可验证的下一步。工作台用于写下问题、交给对话继续和检查账号连接；思考与回应仍在对话中完成。

本说明适用于插件包 **0.2.1**。

## 安装与连接

首版面向支持 Git 插件市场的 Codex 桌面。请先安装并登录 Codex；以下命令需要 Codex CLI。网页、手机和其他宿主不在本版已确认兼容范围内。

在 Codex 的“添加插件市场”中添加 `https://github.com/aideskx/aidesk`，使用 `main` 分支，再安装“AI 书桌”。也可以在终端执行：

```bash
codex plugin marketplace add aideskx/aidesk --ref main
codex plugin add aidesk-minimal@aidesk-minimal-local
```

市场中只有一个插件。市场名 `aidesk-minimal-local` 是固定技术名称，使用 Git 来源后仍保留它。

安装后按宿主提示连接账号。在 WorkOS 托管登录页输入自己的邮箱，填写收到的六位验证码，并确认授权。验证码只填在登录页面。如果当前桌面没有登录按钮，可在终端执行：

```bash
codex mcp login aidesk --scopes openid,offline_access
```

完成后关闭并重新打开 Codex，再打开新对话。首次安装、换来源或账号连接变化后都可能需要重开；请勿通过重复创建“开发验收”连接来解决。

生产连接地址为 `https://aideskx.com/mcp`。它是工具服务入口，直接在浏览器打开不等于安装或登录。

## 使用工作台

也可以直接在对话中提出问题；不必先打开工作台或检查连接。需要了解用法或连接、发送状态时，可以直接问 AI 书桌。

1. 在侧边栏选择“打开 AI 书桌”，或在启用该插件的对话中说“打开 AI 书桌”。
2. 写下一个问题，最多 4000 字符。点击“交给对话继续”，将原文发给宿主对话。
3. 看到“已交给对话”后，回到对话查看回应。“已收到工具回执”仅表示工具已处理，不表示解决方案已经生成。
4. 点击“检查连接”核对账号状态。“已连接”表示本次取得了有效身份，不代表问题已经发送。

若当前界面不能直接发送，可用“复制问题”后回到对话粘贴。发送显示“结果未知”时，先查看对话，避免重复发送。关闭或刷新工作台会丢失未发送草稿；已交给宿主的消息按宿主的历史与隐私设置处理。

没有工作台界面的宿主也可使用工具的文本结果。独立对话侧面板的表现取决于宿主，本版未单独完成该路径的真实验收。

## 更新

先阅读 [版本说明](CHANGELOG.md)，再刷新 Git 市场：

```bash
codex plugin marketplace upgrade aidesk-minimal-local
```

在已验证的 Codex CLI 0.160.0 中，该命令会刷新 Git 市场，并更新已安装插件的磁盘缓存，正常升级无需再次执行 `plugin add`。随后重新打开 Codex，开启新对话和工作台；磁盘已更新不代表运行中的旧会话已经重新加载。

可以用以下命令检查当前安装：

```bash
codex plugin list --marketplace aidesk-minimal-local --json
```

核对同一个 `aidesk-minimal@aidesk-minimal-local` 的版本和 Git 来源；本版目标版本为 `0.2.1`。必要时查看安装缓存中的 `plugin.json`，与发行版的 `SHA256SUMS` 核对；`plugin list` 的 `source.path` 指向市场源，不是安装缓存。真实 AI 书桌 portable 包使用 `0.2.x` 发行版本；早期合成测试包曾显示 `local`，不能据此把真实包的版本忽略。本版不承诺个人市场在后台自动检查或静默更新，也没有额外的自更新程序。

从 `0.2.0` 更新到本版不要求例行重新登录；只有连接确实失效时才需要再次连接。更新失败时先保留错误提示，核对来源与版本，按 [支持方式](SUPPORT.md)联系维护者获取经校验的恢复步骤。

插件包与云端服务分别更新。Skill、图标和清单变化通过市场分发；兼容的工作台与服务变化由现有云端地址提供。安装新版不会把旧版本变成第二个插件。

## 断开与移除

断开账号、卸载插件和移除市场是不同操作。在宿主中断开 AI 书桌账号；若使用 CLI 管理该连接，可执行：

```bash
codex mcp logout aidesk
```

关闭并重新打开 Codex，使当前进程使用新的连接状态。随后按需卸载插件和移除市场：

```bash
codex plugin remove aidesk-minimal@aidesk-minimal-local
codex plugin marketplace remove aidesk-minimal-local
```

卸载不会代为删除宿主对话或 WorkOS 中的身份账号，也不代表所有已签发凭证会即时失效。隐私和账号处理见 [数据说明](PRIVACY.md)及[支持方式](SUPPORT.md)。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 找不到市场或插件 | 确认来源为 `aideskx/aidesk`、分支为 `main`，并检查宿主能否访问 GitHub；仍失败时按支持说明反馈错误提示。 |
| 安装后没有入口 | 重开 Codex 并打开新对话，查看插件是否启用。当前只确认目标桌面范围，不据此判断网页或手机也可用。 |
| 有两个“AI 书桌” | 先查看插件的来源及内部 ID。正式包应为 `aidesk-minimal@aidesk-minimal-local`；“开发验收”是独立测试连接，不是安装必需品。不要仅按显示名称删除。 |
| 原来已装本地开发版 | 同名并不意味着来源已迁移。先用 `codex plugin marketplace list` 核对来源，按维护者给出的迁移步骤处理；不要另外创建同名连接。 |
| “需要连接账号” | 完成上面的登录；若刚断开或重连，先重开宿主再检查。不要把验证码或回调链接发到聊天或 Issues。 |
| 工作台“发送结果未知” | 先查看相关对话；没有收到确认不等于没有发出。 |
| 刷新后仍是旧版本 | 核对 Git `main` 来源、`plugin list` 与安装清单版本，以及是否重新打开了宿主；项目内的同名市场配置可能覆盖用户级来源。仍有问题时按支持说明反馈，不要手动修改安装缓存。 |

服务不保存任务正文或摘要，但宿主、身份提供商和云平台各有自己的数据处理边界。安装前请阅读 [PRIVACY.md](PRIVACY.md)。问题反馈见 [SUPPORT.md](SUPPORT.md)。
