# AI书桌 Plugin · 1.0.7

AI书桌在 Codex 中帮助用户澄清本人目标、衔接独立目标任务、记录必要进展与成果，并按本人意愿分享和继续工作。每人使用自己的账号和书桌。

本地待审候选为 `1.0.7+codex.20261001225309`，尚未公开推送；当前公开稳定版仍为 `1.0.6+codex.20261001192600`。本仓库分发 Plugin 包与配套元数据，代码分发不等于全部用户路径已经验收或社区已经开放。

## 这次更新带来什么

- 对当前社区公开目标及其中选定的成果摘要，增加准确的撤回操作。撤回前核对公开对象、内容版本和状态版本，避免把后来更新的内容误当作用户原先指定的版本处理。
- 撤回进入 Pre/Post 恢复账本；结果不确定时沿原操作号核对。私人结果、更正历史、他人已采用的引用及宿主历史分别保留，不把撤回当作删除全部副本。
- 区分当前社区撤回、普通关闭和旧网络对象撤回。服务尚未提供相应工具时，如实报告不可用，不套用不匹配的操作。

此前版本的目标协作、结果记录/更正/读取、分享、互动与通知、受限恢复账本、官方 CLI 更新和失败保留能力继续提供。草稿和既有私人目标不会因分享默认值而自动公开。

## 安装与使用

官网：[aideskx.com](https://aideskx.com)。沿 Codex 官方 Plugin 机制安装或更新 AI书桌，在新对话中说“打开AI书桌”。产品介绍不要求登录；本人服务通过宿主原生认证核对身份及权限。

本包不写死长期 CLI 版本。宿主需要支持包内 CLI-native 声明、MCP 与 Hook；启用和信任按宿主正常流程办理。磁盘安装成功不代表已有会话已经加载新连接。

最低支持版本保持 `1.0.5+codex.20261001120032`。社区功能受服务端开关、账号权限及实际工具目录控制。

## 验证边界

本地撤回服务回归覆盖准确版本、原号对账、公开状态变化、导出与删除；Hook 回归覆盖撤回原件的版本绑定。云端精确撤回验收仍在进行中。官方 CLI 对本候选的隔离安装已读回 1.0.7、四个 enabled/untrusted Hook 和 reconcile 无变化；这不代表 Hook 已获信任或业务连接已生效。真实活动宿主仍为 1.0.6。

1.0.6 的真实认证连接已验证合成目标的服务暂停/修改/恢复/结束、结果更正、分段导出、取消删除、最终删除和本机精确清理；数据库只读后检确认本轮正文及请求/回执擦除，原文件与独立导出保持。此证据有明确版本范围，不能代替 1.0.7 的全部真实用户路径。

仅首句“打开AI书桌”的完整自然入口、多轮协作、桌面 UI/AX、第二宿主及真实家庭路径尚未完成全部验收，不能从接口存在或测试通过推定全部原始功能已经上线。
