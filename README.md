# AI 书桌

帮助家长和孩子用 AI 推进一个当前问题。工作台把问题交给对话，思考与回应继续在对话中完成。

本说明适用于插件包 **1.1.0**。

## 本版适用范围

本版验证 Codex Git 安装下的原生账号管理与一个 Skill。**需要当前 OpenAI 账号已有所引用私人应用的访问资格。** 公开仓库可以下载，不代表任何账号都有应用访问资格；Git 安装不会创建应用或授予共享权限。本版不是面向所有账号的公开上架版本。

包格式由 portable 直连 MCP 改为官方原生 `.codex-plugin/plugin.json` 与 `.app.json` 应用引用。生产服务仍为 `https://aideskx.com/mcp`，没有新服务或包内凭据。旧 `0.2.x` 用户应先确认应用访问资格，再迁移；缺少账号控件不算完整安装成功。

## 安装

在已登录相应账号的 Codex 中说：

> 从 GitHub aideskx/aidesk 安装 AI 书桌插件。

对应官方 CLI 命令：

```bash
codex plugin marketplace add aideskx/aidesk --ref main
codex plugin add aidesk-minimal@aidesk-minimal-local
```

安装后在同一个 AI 书桌内核对应用／账号管理与 `Solve One Problem` 技能。需要登录时从宿主账号控件进入 WorkOS，填写邮箱验证码并授权。验证码、回调和令牌不要发到聊天或 Issues。本版使用宿主应用连接，不使用旧 `codex mcp login aidesk` 直连配置作为替代。

若还有旧云端 AI 书桌，先确认 Git 版完整，再按准确来源卸载旧**安装项**，保留被引用的云端应用定义。不要仅按同名删除应用或断开所有账号。没有应用访问资格时联系维护者，不重复创建同名插件。

## 使用

直接在对话中提出问题即可，也可打开工作台，写下问题后点击“交给对话继续”。

- “已连接”：本次账号检查成功，不表示问题已发送。
- “已交给对话”：回到对话查看回应。
- “工具回执”：工具完成处理，不表示解决方案已生成。
- 发送结果未知：先查看对话，避免重复发送；不能发送时可复制问题到对话。

未发送草稿仅在当前页面内存中，关闭或刷新会丢失。服务不保存任务正文或摘要，宿主及供应商的数据边界见 [PRIVACY.md](PRIVACY.md)。

## 更新与版本

发行版本为纯数字 `主版本.次版本.修订号`。市场 `aidesk-minimal-local`、插件 `aidesk-minimal` 及应用引用保持稳定；正常更新不增加第二个插件。更新跟踪 `main`，创建 GitHub 标签或 Release 本身不会升级已安装包。

宿主可能在启动或市场加载时后台刷新；**个人 Git 市场的固定自动检查周期尚无已确认承诺**。企业工作区市场的每日同步不能直接套用。本项目没有自制更新器或后台仓库轮询。自动刷新实测与主动升级分别记录，磁盘更新也不等于旧会话已经加载。

需要立即更新时执行：

```bash
codex plugin marketplace upgrade aidesk-minimal-local
```

这是手动触发升级。随后核对插件详情的版本、账号及技能，必要时重开宿主／新对话。普通包更新不应要求例行重新登录；只有连接失效时才重连。更新失败保留可用版本并联系维护者，不手工修改缓存。

已发布版本内容固定，每版绑定准确提交与 `SHA256SUMS`；不覆盖旧版本、不移动旧标签、不强推。修复用更高数字版本发布。维护者可固定已验证标签或提交恢复；禁用插件不等于停止市场刷新文件。包更新与生产部署分开管理。
