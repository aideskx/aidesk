# AI书桌

把想学习、创造或实践的事情整理成个人目标，交给独立的Codex任务推进，再回到书桌找回材料、必要进展和成果。是否分享、采用他人的内容或参与协作，由你决定。

## 安装与打开

向Codex发送：

> 从GitHub安装Codex插件 aideskx/aidesk

安装后新建任务，发送：

> 打开AI书桌

首次使用时，按宿主显示的连接入口完成网页登录与授权，再回到原任务继续；已有有效授权时直接使用。验证码在登录页输入。之后可以继续已有目标，也可以说出一个新目标，由Codex帮助整理。

官网：[aideskx.com](https://aideskx.com)。这是AI书桌的GitHub技术分发源；Plugin的Git来源由[Codex官方安装机制](https://learn.chatgpt.com/docs/developer-commands#codex-plugin-marketplace)管理。
