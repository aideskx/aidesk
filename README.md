# AI书桌 Plugin 技术预发布

普通用户向 Codex 发送：

> 从GitHub安装Codex插件 aideskx/aidesk

安装后新建任务，发送“打开AI书桌”。官网：https://aideskx.com

当前包版本 `0.3.2+codex.20260918142532`。同一个 Plugin 包含入口 Skill、MCP 连接、一次性更新程序和教学接线。教学仍为开发验证范围，真实家庭尚未开放；账号与教学能力以实际授权和服务返回为准。

进入教学时，宿主先读本机核心，再通过同一 MCP 完整取得服务器当前活动且兼容的教学 Skill，读完主文件和全部附属文件后组织教学。服务器维护教学工作方式、方法和评价指导，兼容内容更新无需重新安装 Plugin。宿主 Agent 负责理解与教学，服务负责权限与必要学习事实；服务器不会替代宿主逐轮教学。未读完整、失效或不兼容时停止依赖该包的教学。

本包已经过本机／指定开发环境／合成代表场景验证，范围包括完整 Skill 加载、按计划与随时提问、应用与应试、事实保存和跨次接续、纠错及保留事实的内容恢复。所配官网只读展示由独立服务与网站维护。结果不证明全年龄、全学科或真人学习效果；完整 Skill 加载仍有明显等待，模块化和跨次缓存尚未交付。

公开安装／自动更新后的同候选教学组合尚未验收，MacBook／Windows同版本路径及真实家庭也尚未验收；本机开发包通过不能代替这些结果。

打开AI书桌会检查官方稳定版本，需要时通过宿主官方 Plugin CLI 安装。只想检查或暂不更新，可以明确告诉 Codex。不会关闭 Codex 后后台轮询；检查失败不会冒充最新版。GitHub 公开下载层与服务均有缓存，发布后各地区可能需数分钟才看到新版。发现新版、磁盘已安装、当前连接已加载是分别核验的状态；新任务仍使用旧连接时可能需要重启 Codex。

更新程序及其基础完整性／版本检查模块沿用此前公开版本，没有在本包改写安装、来源或登录机制。更新依赖宿主已有 Node（20+）、可核实的 Codex CLI 与执行能力，宿主必要确认仍然有效。来源冲突、固定其他版本或缺少执行能力时说明停点。历史自动更新只在当时设备与包上通过，不保证本次公开组合。

发布元数据 `release.json` 与完整包在同一 Git 提交中；安装后按 `packageDigest` 核验实际文件。包摘要 `2caf2b973446d83e17f7c1200cc75e1add23bae0260aa2abf52355c9c7fbc9c5`，`SHA256SUMS` 覆盖全部18个包文件与发布元数据。`minimumSupportedVersion=0.3.0` 保留原外层更新兼容设置，不代表该旧版已有完整教学能力，也不是产品授权。

上一公开提交 `a3b8fbf77d08904c8ab6082e24688ef2cfae447b`（`0.3.2+codex.20260914080525`）保留在历史中；更早 C 提交 `349aa1c252eec1b54978e3553238c3d433353db1` 的自动安装与新连接曾有本机核验。恢复须使用同提交配套包及元数据，另核当前服务兼容性；更新程序不自动降级。旧公开包没有本次教学能力，回退不能宣称教学零降级，服务器内容恢复也不能删除新增学习事实。
