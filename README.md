# AI书桌 · V2.2 本地固定候选

AI书桌面向孩子和家长，连接 Agent、工具与真实用户社区，帮助家庭驾驭 AI、共同学习和实践。目标 Plugin 是首个核心 Plugin，目标社区是平台社区的首个业务场景；其他 Plugin 各有用途，不以预装目标 Plugin 或创建目标为前提。

本页对应 `0.3.2+codex.20260926220140`，拟用 `aideskx/aidesk` 的 `codex/v22-candidate-220140`。当前仅完成本地候选准备，未公开推送、提升 `main` 或开放社区；完整 V2.2 仍未验收完成，总控将在剩余缺口收敛后决定最终冻结。

## 能力与分享边界

- 从问题、兴趣或想法开始，充分澄清目标，再衔接独立 Codex 任务。书桌保留必要进展、成果引用与任务入口；Codex 负责规划、工具、协作、执行和验证。文件引用不等于上传或跨设备可读。
- 新正式目标默认分享公开介绍和选定的必要进展／成果摘要；定稿时展示准确内容与开关，可关闭本目标分享或调整后续默认。草稿、完整对话及旧私人目标不自动公开。其他 Plugin 的分享规则分别确定。
- 目标社区实现发现、采用、点赞、私人收藏、评论／回复、本人消息及通知设置，以及最小举报与处置。实际可用性仍由当前服务、准入、本人权限与真实结果确定；无人回应不影响个人目标继续。
- 关闭来源、取消原操作、导出或删除本人数据各有准确范围。通知不复制源正文，不保证即时推送或后台常驻；本人删除不能撤销独立运营处置或删除其他人的内容。

每人使用个人账号和书桌。家长获准查看与本人使用分别办理，不因亲属关系、同设备或订阅自动取得他人资料和修改权限。原账号、旧私人资料、已付期限及既有覆盖保持。
