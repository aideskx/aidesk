# AI书桌 Plugin · 1.0.9

AI书桌在 Codex 中帮助用户澄清本人目标、衔接独立目标任务、记录必要进展与成果，并按本人意愿分享和继续工作。每人使用自己的账号和书桌。

本仓库提供 `1.0.9+codex.20261002020027` 的 Plugin 包与配套元数据。代码分发不等于全部用户路径已经验收或社区已经开放。

## 这次更新带来什么

更新器发生异常时，增加固定阶段 `phase` 和白名单错误码 `code` 的最小诊断，帮助区分参数解析、CLI 发现、取得更新锁、执行更新和释放锁。没有或不在白名单的错误码记录为 `null`；不输出原始错误消息、堆栈、路径、命令输出或凭据。

释放锁失败时保留已经确认的更新结果，并同时返回诊断与非零退出码。未知更新结果继续保持未知，不据此自动重试。正常更新事务、原有锁和有界单次命令保持原合同。

此次增强没有查明此前 1.0.8 自然升级失败的原始 errno。离线模拟的错误码不能追认为该次真实故障原因，也不代表自然升级全链或全部功能已通过。

## 安装与使用

官网：[aideskx.com](https://aideskx.com)。沿 Codex 官方 Plugin 机制安装或更新 AI书桌，在新对话中说“打开AI书桌”。产品介绍不要求登录；本人服务通过宿主原生认证核对身份及权限。

本包不写死长期 CLI 版本。宿主需要支持包内 CLI-native 声明、MCP 与 Hook；启用和信任按宿主正常流程办理。磁盘安装成功不代表已有会话已经加载新连接。发行元数据最低支持版本保持 `1.0.5+codex.20261001120032`；社区功能受服务端开关、账号权限及实际工具目录控制。
